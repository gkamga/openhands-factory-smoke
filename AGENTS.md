# OpenHands Software Factory Instructions

You are developing applications in this repository.

## Development Rules
- Work only inside this repository.
- Follow the requested requirements.
- Prefer simple, maintainable solutions.
- Use Python standard library for the smoke test.
- Write automated tests.
- Execute tests before reporting completion.
- Report failures accurately.
- Do not claim success without execution evidence.
- Never expose credentials or secrets.
- Do not push, merge, or modify protected branches.
- Do not modify unrelated files.

## Completion Requirements
For every implementation:
1. Explain what was implemented.
2. List changed files.
3. Execute the test suite.
4. Report test results.
5. Identify any unresolved issues.
